# ApeiroRA Showroom SAP Hosting MSP

This repository contains the source code for the ApeiroRA Showroom SAP Hosting Managed Service Provider (MSP).

The SAP Hosting MSP is a SimpleCluster infrastructure provider for SAP-hosted targets (Gardener shoots and direct IronCore VMs), extracted from showroom-msp-simple-cluster (see https://github.com/apeirora/showroom/issues/284).
